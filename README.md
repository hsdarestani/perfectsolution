# Perfect Solution GmbH Webshop

Erste Webshop Version für Perfect Solution GmbH in Dietzenbach.

## Konzept

Die Oberfläche orientiert sich funktional an professionellen Shops für Reinigungsbedarf und Hygiene, verwendet aber ein eigenes Design und eine eigene Markenwirkung.

Enthalten sind:

* responsive Startseite
* professionelle Produktkategorien
* Produktsuche
* Kategorie Filter
* Demo Produktkatalog
* Anfragekorb mit Mengenauswahl und Speicherung im Browser
* Geschäftskonto Anfrage
* Beratung und Kontakt Bereiche
* vorbereitete rechtliche Seiten
* SEO Basis und strukturierte Unternehmensdaten
* optimierte mobile Navigation

## Wichtig vor Livegang

Die aktuell hinterlegten Produkte sind Demoartikel. Vor dem Livegang werden benötigt:

* echter Produktkatalog
* Preise und Steuersätze
* Lagerbestand
* Lieferbedingungen
* Zahlungsarten
* vollständige Firmenanschrift
* Vertretungsberechtigte Person
* Handelsregister Daten
* Umsatzsteuer ID
* Kontakt E Mail und Telefonnummer
* finaler Checkout und Backend Anbindung

## Technik

Statisches HTML, CSS und JavaScript ohne Build Schritt. Dadurch ist die erste Version direkt auf Cloudflare Pages, GitHub Pages oder jedem normalen Webspace deploybar.
